# 🤖 웹 프론트엔드 AI 서브 에이전트 지침서 (`web_agent_guide.md`)

## 1. 연동 기획 명세
* **도메인**: 묘록 (Myorok) - 랜딩 페이지 및 정책 고지 웹사이트.
* **타겟 플랫폼**: Next.js App Router 정적 사이트 렌더링.
* **관련 문서**: `human_docs/frontend/web_ui_spec.md`

## 2. 목적 및 개발 지침
본 지침은 묘록의 프론트엔드 웹 페이지를 개발하거나 유지보수하는 AI 에이전트를 위한 규칙입니다.

### 아키텍처 및 디자인 시스템
* **App Router 라우팅**: Next.js 14+ App Router 구조를 따라 정적 페이지를 구성합니다. 약관(`terms`), 개인정보처리방침(`privacy`) 등의 규제 준수 문서를 렌더링합니다.
* **디자인 시스템**: 
  * 기본 폰트로 `Noto_Sans_KR`을 전역 적용합니다.
  * 지정된 주요 색상(Primary: `#5DB075`)과 보조 색상 조합을 엄격히 준수해야 합니다.
* **서버사이드 렌더링 최적화**: 가능한 한 클라이언트 컴포넌트(`"use client"`)의 사용을 최소화하고 정적 서버 컴포넌트를 지향하여 속도를 극대화합니다.

## 3. 제약 조건
* 단일 파일 **300줄 하드 한계** 제약을 준수해야 합니다.
* 페이지와 레이아웃 구조는 `app/` 폴더 기반의 규칙을 따라야 합니다.
