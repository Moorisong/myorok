# 🌐 웹 서비스 화면 구조 및 라우팅 (`web_ui_spec.md`)

이 문서는 **묘록 (Myorok)** 서비스의 웹 페이지 화면 구조와 라우팅, 디자인 시스템 사양을 정의합니다. 사용자 약관 제공 및 법적 규제 준수를 위해 정적 사이트로 Next.js App Router를 사용하여 구축되어 있습니다.

---

## 1. 웹 페이지 라우팅
```text
/ (웹 홈) -> 묘록 랜딩 및 앱 소개 페이지
├── terms (이용약관) -> 묘록 서비스 이용 표준 약관 페이지
├── privacy (개인정보처리방침) -> 개인식별정보 미수집 및 Kakao OAuth 처리 등 방침 고지 페이지
└── partial-delete (데이터 삭제 안내) -> 카카오 연동 해제 및 데이터 삭제 절차 가이드
```

---
