# 🎨 페이지별 UI 구조 및 비즈니스 로직 (`ui_design_spec.md`)

이 문서는 **묘록 (Myorok)** 서비스의 모바일 앱 및 웹 페이지의 화면 구조, 주요 기능, 비즈니스 로직과 디자인 사양을 정의합니다.

---

## 📱 1. 모바일 앱 화면 구조 및 사이트맵

Expo Router의 파일 기반 라우팅 규칙을 사용하며, 메인 화면 그룹은 `(tabs)` 레이아웃에 위치합니다.

### 🗺️ 모바일 앱 라우팅 및 화면 구조
```text
/ (루트 레이아웃)
├── 로그인 화면 (LoginScreen) -> 로그인되지 않은 경우 노출
└── (tabs) / (메인 탭 네비게이션)
    ├── index (오늘 기록) -> 펫의 일일 건강 지표 기록
    ├── calendar (달력) -> 월별 건강 상태 리포트 및 상세 기록 조회
    ├── charts / (차트/통계)
    │   ├── index (차트 홈) -> 주요 건강 지표 변화 시각화
    │   ├── summary (기록 요약) -> 펫 기록 요약 통계
    │   └── custom (커스텀 지표) -> 유저가 정의한 혈액검사 등 커스텀 수치 변화 차트
    ├── comfort (쉼터) -> 익명 기반 집사 커뮤니티 공간
    ├── settings / (설정)
    │   ├── index (설정 홈) -> 프로필 관리, 데이터 초기화, 구독 관리 등
    │   ├── pets (고양이 프로필 관리) -> 고양이 등록/수정/삭제 및 전환
    │   ├── notifications (알림 설정) -> 댓글, 활동 기록 리마인더 수신 토글
    │   ├── block-list (차단 목록) -> 쉼터 내 차단한 사용자 관리
    │   ├── reference-memos (참고 메모) -> 복용 중인 약물, 선호 사료 메모
    │   └── about (서비스 정보) -> 묘록 앱 정보 및 이용 약관 연동
    └── records / (기록 추가 허브)
        ├── index (기록 선택) -> 추가하려는 일일 지표 및 특수 항목 허브
        ├── medicine (영양제/약물 관리) -> 복용 체크리스트 및 관리
        ├── fluid (수액 기록) -> 피하 수액 투여 정보 기록
        └── custom-metrics (커스텀 지표 입력) -> 고유 건강 지표 수치 기록
```

## 💻 2. 각 페이지별 주요 기능 및 비즈니스 로직 요약

### 1) 오늘 기록 (`app/(tabs)/index.tsx`)
* **핵심 기능**: 특정 날짜(기본값: 오늘)의 펫 일일 건강 항목 기록 및 수정.
* **주요 비즈니스 로직**:
  * 배변 상태(소변 카운트, 대변 카운트, 묽은 변 카운트), 구토 카운트, 수분 섭취량(ml), 특이사항 메모 입력.
  * 하루에 단 한 건만 기록이 존재하도록 SQLite `UNIQUE(petId, date)` 제약 조건 기반의 Upsert 동작을 수행함.

### 2) 달력 (`app/(tabs)/calendar.tsx`)
* **핵심 기능**: 월별 달력 컴포넌트를 활용하여 펫의 기록 여부를 아이콘(배변, 구토, 메모 등)으로 시각화.
* **주요 비즈니스 로직**:
  * 선택된 날짜의 상세 기록 리스트 출력 및 수정 연결.
  * 월 변경 시, 해당 월의 전체 `daily_records` 데이터를 데이터베이스에서 일괄 조회하여 캘린더 마킹 렌더링.

### 3) 차트 및 기록 요약 (`app/(tabs)/charts/...`)
* **핵심 기능**: 기록된 건강 데이터를 그래프 및 리포트 형태로 제공하여 장기적 수치 변동성 모니터링.
* **주요 비즈니스 로직**:
  * **주요 통계 차트 (`index.tsx`)**: 소변, 대변, 묽은변, 구토 횟수 추이를 선/바 그래프로 표현.
  * **기록 요약 (`summary.tsx`)**: 주/월 단위 평균 배변 횟수, 총 구토 횟수 등의 통계 리포트 생성.
  * **커스텀 지표 차트 (`custom.tsx`)**: 체중, 체온, 혈당 등 사용자가 직접 추가한 커스텀 물리/화학 수치를 꺾은선 그래프로 시각화.

### 4) 쉼터 (`app/(tabs)/comfort.tsx`)
* **핵심 기능**: 고양이를 돌보는 보호자들이 서로 위로와 고민을 나누는 완전 익명의 커뮤니티 공간.
* **주요 비즈니스 로직**:
  * **자정 자동 폭파**: 매일 자정에 이전 작성 글이 자동 삭제되어 기록이 남지 않도록 보장함.
  * **익명 닉네임**: 기기 고유 ID(`deviceId`)를 해싱한 고정 해시어와 임의의 숫자를 조합하여 고유한 익명 닉네임(`예: 미르5102`) 제공.
  * **신고 및 차단**: 누적 신고 수 5회 이상 시 자동 블라인드(hidden), 차단한 사용자의 글/댓글은 화면에서 즉시 필터링 처리.
  * **도배 방지**: 1시간 이내 게시글 작성 빈도 조절, 댓글은 1분 10개 및 5분 50개 제한(임시 대기 상태 부여).

### 5) 설정 및 서브 기능 (`app/(tabs)/settings/...`)
* **핵심 기능**: 사용자 및 앱 세팅 통제.
* **주요 비즈니스 로직**:
  * **고양이 프로필 관리 (`pets.tsx`)**: 고양이 추가, 이름 수정, 소프트 삭제(`deletedAt` 플래그). 다묘 가정을 지원하기 위해 펫 전환 시 로컬 상태가 갱신됨.
  * **참고 메모 (`reference-memos.tsx`)**: 영양제/약물 메모, 사료 선호도(기호성)에 대한 자유 양식 기록 보관.
  * **구독/결제 시뮬레이션**: Google Play Store 인앱 결제 상태 대응 테스트 섹션 제공 (체험 기간 임의 설정, 만료 상태 갱신 테스트 가능).

## 🌐 3. 웹 서비스 화면 구조 및 라우팅

사용자 약관 제공 및 법적 규제 준수를 위해 정적 사이트로 Next.js App Router를 사용하여 구축되어 있습니다.

### 🗺️ 웹 페이지 라우팅
```text
/ (웹 홈) -> 묘록 랜딩 및 앱 소개 페이지
├── terms (이용약관) -> 묘록 서비스 이용 표준 약관 페이지
├── privacy (개인정보처리방침) -> 개인식별정보 미수집 및 Kakao OAuth 처리 등 방침 고지 페이지
└── partial-delete (데이터 삭제 안내) -> 카카오 연동 해제 및 데이터 삭제 절차 가이드
```

## 🎨 4. 디자인 시스템 사양 요약

### 🎨 컬러 팔레트 (COLORS)
* **주요 색상 (Primary)**: `#5DB075` (부드러운 녹색 - Soft Green)
* **보조 색상 (Secondary)**: `#6B6B6B` (따뜻한 회색 - Warm Gray)
* **배경 및 서피스**: 배경 `#F7F7F7`, 카드/컨테이너 `#FFFFFF`, 플레이트 `#FAFAFA`
* **텍스트**: 본문 기본 `#2E2E2E` (어두운 회색), 서브 정보 `#8A8A8A` (연한 회색)
* **상태 컬러**: 경고 `#D4915C` (살구빛 앰버), 에러 `#E57373` (소프트 레드)
* **차트 테마**: 수분량 `#60A5FA` (블루), 수액 투여 `#34D399` (에메랄드)

### ✍️ 타이포그래피 규칙
* **모바일**: 기본 폰트 적용 (System Font)
  * Title: 28px, Bold
  * Heading: 20px, SemiBold
  * Body: 16px, Regular
  * Caption: 14px, Regular
* **웹**: `Noto_Sans_KR` 웹폰트 전역 임베딩 (가중치 400, 500, 600, 700, 800)

### 📱 레이아웃 가이드라인
* 모바일 노치 영역 대응을 위한 `SafeAreaView` 전면 적용.
* 기기 가로폭 변동에 대한 유연한 처리를 위해 Flexbox 기반의 퍼센트/비율 레이아웃(Grid) 구조 유지.
